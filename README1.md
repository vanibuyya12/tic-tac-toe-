
# VOSC Activity-1 - Tic-Tac-Toe

## Project Description
Tic-Tac-Toe is a simple two-player game developed using
HTML, CSS and JavaScript.

Players take turns placing X and O in a 3x3 grid.
The first player to get three marks in a row, column
or diagonal wins the game.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Two-player game
- Win detection
- Draw detection
- Scoreboard
- Restart round option
- Reset scores option
- Mobile-friendly design

## How to Run
1. Download or clone the repository.
2. Keep all four files in the same folder.
3. Open index.html in a web browser.
4. Start playing the game.

## How to Play
1. Player X starts the game.
2. Player O plays after X.
3. Players take turns selecting empty cells.
4. Get three marks in a row, column or diagonal to win.
5. If all cells are filled without a winner, the game
   ends in a draw.
6. Click Restart Round to play again.
7. Click Reset Scores to clear the scoreboard.
